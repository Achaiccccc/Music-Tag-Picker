# 设计说明

## 目标

做一个部署在绿联 NAS 上的 Docker 应用。对本地音乐刮削时，列出各平台搜索到的候选，展示歌手、专辑、时长、封面和歌词，由用户选定后再写入文件。

现有 Music Tag Web 的自动刮削不能指定最终命中的版本。它的手动搜索列表最多约 10 条，而且当前环境下网易云搜索返回空结果。

## 范围

`Music-Tag-Picker/` 现在就是这个应用，不再只做连通性探测。页面分三栏：左侧目录树和本地搜索，中间当前文件夹的音频，右侧在线搜索和写入。

已经做到：

- 浏览挂载到容器 `/music` 的目录。左侧按层展开，从所选根目录最多向下 5 层；第 5 层只显示文件，不再进入子目录。
- 目录树下方按歌名、歌手、文件名和相对路径做模糊搜索。关键词按空白拆开，每一段都要出现；最多返回 40 条。
- 点选文件后，按文件名预填歌名和歌手，用户可以改。常见形式是 `歌名 - 歌手.扩展名`，也接受 `–`、`—`、`－`。开头的 `01.` 或 `01 -` 这类曲目号会去掉。单独的连字符不拆分。
- 勾选一个或多个平台后搜索，展示全部返回的候选，不截成前 10 条。点开一条可看歌词，确认后再写入。
- 写入字段为标题、歌手、专辑、歌词和封面。歌手用 ` / ` 连接。写入前会按候选重新拉取歌词和封面，不信任页面里临时填的歌词正文。

当前不做：

- 下载音频
- 未选中候选时自动写入
- 写入 `wma`、`ape`、`aiff`、`aif`、`wv`。这些格式可以在列表里看到，点写入会提示暂不支持

可写入的格式：`mp3`、`wav`（ID3）、`flac`、`ogg`、`opus`、`m4a`、`mp4`、`aac`。`m4a`、`mp4`、`aac` 只嵌入 JPEG 或 PNG 封面；WebP 会跳过封面并在结果里说明。

## 部署

镜像为 Python 3.12 Alpine，依赖 `mutagen==1.47.0`。容器内服务端口 8080，Compose 映射为宿主机 8090。`MUSIC_ROOT` 固定为 `/music`。

绿联上的音乐目录挂到容器内的 `/music`。当前这台 NAS 的写法是：

```yaml
volumes:
  - "/home/阿柴/Music:/music"
```

路径含中文，需要加引号。只改冒号左侧。浏览器通过 `http://<NAS地址>:8090` 访问；UGOS 应用链接使用的是同一映射。

## 平台结论

2026-11-12 在开发机上，用「魔鬼中的天使 / 田馥甄」验证四个平台都能取到原唱的元数据、封面和带时间轴歌词。同一天，用户在 NAS 容器里打开应用，四个平台的搜索都能出结果，并确认选曲写入流程已经跑通。

| 平台 | 结果 | 实现时要注意 |
| --- | --- | --- |
| QQ 音乐 | 第一页第一条就是原唱。封面 JPEG 约 75 KB。歌词 53 行带时间轴 | 有歌手时用「歌名 歌手」搜索。封面使用专辑 `pmid` 拼图片地址 |
| 酷狗 | 第一条就是原唱。封面 JPEG 约 63 KB。歌词解码后 57 行带时间轴 | 有歌手时用「歌名 歌手」搜索。歌词下载内容是 Base64。封面地址里的 `{size}` 要换成像素尺寸 |
| 咪咕 | 只搜歌名时第一条是其他歌手的现场版。加上歌手后第一条是原唱。歌词 53 行带时间轴 | 查询顺序是「歌手 歌名」。封面是相对路径，需要加上 `https://d.musicapp.migu.cn`。只搜歌名时必须保留候选列表，不能取第一条 |
| 网易云 | 原唱存在，歌曲 ID 296837，专辑 My Love，时长 238 秒。封面 JPEG 约 114 KB。歌词 62 行带时间轴 | 只按歌名搜索，最多翻 10 页、300 条。原唱排在第 120 条之后，提前停止会漏掉它 |

这首歌四个平台都没有返回译文。

同一天，NAS 上的 Music Tag Web 搜索这首歌时，网易云接口 HTTP 200，响应 `data` 为空数组，页面显示「暂无歌曲信息」。那是另一个应用的接口，不作为本应用的出网结论。

## 匹配与写入

- 歌名完全相同加 100 分，歌名被包含加 40 分，歌手全名相同加 60 分。歌名里出现 live、remix、cover、dj、翻唱、伴奏、纯音乐则减 35 分。完全同名、歌手吻合且没有上述扣分的条目标为推荐，排在前面。现场版和翻唱仍留在列表里。扣分只看歌名，不看专辑名。
- 歌手按 `,`、`/`、`、`、`;`、`&` 拆开后做全名相等。不能用子串包含，否则「田馥甄的小迷妹」会误判成田馥甄。
- 封面只从 `music.126.net`、`y.gtimg.cn`、`y.qq.com`、`migu.cn`、`kugou.com` 下载。路径必须留在 `MUSIC_ROOT` 内，不能包含 `..`。
- 日志里的歌词参数会改写成占位，不把歌词正文打出来。

## 后续事项

以下尚未实现：

- 网易云超过 300 条后不再翻页。若原唱落在更后面，当前列表里不会出现。
- 专辑名里的演唱会、现场标记不参与扣分，精确同名时仍可能标为推荐。
- `m4a`、`mp4`、`aac` 不能嵌入 WebP 封面。
